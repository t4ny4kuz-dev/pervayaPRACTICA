# Эмулятор оболочки UNIX (этап 1: REPL)

## 1. Общее описание

Графический эмулятор командной строки UNIX-подобной ОС на Python
(tkinter, без внешних зависимостей). Этап 1 — минимальный прототип:
работает диалог с пользователем (REPL), команды пока являются
заглушками.

Структура репозитория:

```
src/     исходный код (tokenizer.py, shell.py, gui.py, main.py)
tests/   модульные тесты (unittest)
run.sh, run.bat, Makefile   запуск и тесты
```

## 2. Описание функций и настроек

**Настройки запуска**

| Параметр | Описание |
|----------|----------|
| `--vfs ИМЯ` | имя виртуальной ФС, показывается в заголовке окна (по умолчанию `vfs`) |

**Окно.** Заголовок: `Эмулятор - [имя VFS]`. Приглашение в формате
`user@emulator:~$`. Клавиши: `Enter` — выполнить, `↑`/`↓` — история,
`Home` — начало ввода, `Ctrl+L` — очистить экран. Вывод и приглашение
нельзя стереть.

**Парсер аргументов** (`src/tokenizer.py`):

- `"двойные"` кавычки сохраняют пробелы, внутри работают `\"` и `\\`;
- `'одинарные'` кавычки сохраняют всё буквально;
- вне кавычек `\ ` экранирует следующий символ;
- `""` даёт пустой аргумент; `x"y z"` склеивается в `xy z`;
- незакрытая кавычка или слеш в конце строки — сообщение об ошибке.

**Команды**

| Команда | Описание |
|---------|----------|
| `ls [арг...]` | заглушка, печатает аргументы |
| `cd [арг...]` | заглушка, печатает аргументы |
| `help` | список команд |
| `clear` | очистить экран |
| `exit` | выйти |

Неизвестная команда: `команда не найдена`.

## 3. Сборка и тесты

Сборка не требуется, нужен Python 3.9+ с tkinter.

```
make test                 # или:
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 4. Примеры использования

Запуск:

```
./run.sh --vfs myvfs      # Linux / macOS / Git Bash
run.bat --vfs myvfs       # Windows
make run ARGS="--vfs myvfs"
```

Сеанс:

```
user@emulator:~$ ls -l "my dir" 'a b'
ls: ['-l', 'my dir', 'a b']
user@emulator:~$ cd ""
cd: ['']
user@emulator:~$ ls "abc
shell: ошибка разбора: незакрытая кавычка "
user@emulator:~$ foo
foo: команда не найдена
user@emulator:~$ exit
```
